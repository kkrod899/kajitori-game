# Claude・Codex相互レビューワークフロー

## 1. 正本の優先順位

判断が衝突した場合は、上にある文書を優先します。

| 優先 | 正本 |
|---:|---|
| 1 | ユーザーの最新の明示指示 |
| 2 | `docs/PRODUCT_BRIEF.md` |
| 3 | `docs/DECISIONS.md` |
| 4 | `HANDOFF.md` |
| 5 | `reviews/` 内のレビュー記録 |
| 6 | 過去のチャット内容 |

## 2. 役割

1つの作業単位では、担当を分けます。

| 役割 | 主な責任 |
|---|---|
| Implementer | 合意済み範囲だけを実装し、検証結果と差分を提示する |
| Reviewer | 実装を変更せず、欠陥、思想とのズレ、回帰、安全性を確認する |
| User | 重要なプロダクト判断、範囲拡張、競合する提案を決定する |

## 3. 標準サイクル

| 段階 | 担当 | 成果物 |
|---:|---|---|
| 1. Slice定義 | Implementer | 目的、非目標、変更予定ファイル、受入条件 |
| 2. 事前レビュー | Reviewer | 想定漏れ、設計リスク、追加すべき受入条件 |
| 3. 判断反映 | Implementer | Accepted / Rejected / Deferred の回答 |
| 4. 実装 | Implementer | 小さく限定された差分 |
| 5. 検証 | Implementer | 実行した確認と結果 |
| 6. 事後レビュー | Reviewer | Findings、残存リスク、承認可否 |
| 7. 引き継ぎ | Implementer | `HANDOFF.md` と必要な決定記録の更新 |

## 4. レビュー指摘の形式

各指摘には次を含めます。

| 項目 | 内容 |
|---|---|
| Severity | P0 / P1 / P2 / P3 |
| Location | ファイルと行、または画面・操作 |
| Observation | 確認できた事実 |
| Impact | ユーザーやデータへの影響 |
| Principle | 関係するプロダクト原則ID |
| Recommendation | 最小の修正方向 |
| Evidence | 再現手順、ログ、検証結果 |

### 重大度

| 等級 | 定義 |
|---|---|
| P0 | データ損失、安全上の重大問題、利用不能 |
| P1 | 中心機能が意図どおり動かない、思想を大きく損なう |
| P2 | 重要な使いにくさ、限定的な誤動作、将来の回帰リスク |
| P3 | 軽微な改善、保守性、表現上の提案 |

## 5. 指摘への回答

Implementerは、すべての指摘に次のいずれかで回答します。

| 状態 | 使用条件 |
|---|---|
| Accepted | 指摘を認め、今回修正する |
| Rejected | 根拠付きで指摘を採用しない |
| Deferred | 指摘を認めるが、理由と追跡先を示して後続へ回す |

曖昧な「確認しました」「今後検討します」だけで閉じません。

## 6. 競合と同時編集

- 同じファイルをClaudeとCodexが同時に編集しない。
- Reviewerは、レビューが完了するまでアプリ本体を変更しない。
- 意見が割れた場合、両案、利点、欠点、推奨案を表にしてユーザーへ判断を求める。
- プロダクト原則を変更する提案は、コードより先に文書レビューを行う。
- チャットでの重要な合意は `docs/DECISIONS.md` に移す。

## 7. 完了条件

作業単位は、次をすべて満たして完了です。

- 受入条件が明記されている。
- 変更対象と非対象が説明されている。
- 必要な検証が成功している。
- P0/P1の未解決事項がない、またはユーザー承認付きでDeferredになっている。
- `HANDOFF.md` が現在の状態と一致している。
- 新しいプロダクト判断が `docs/DECISIONS.md` に残っている。

## 8. 省トークンレビュー

- Reviewerへリポジトリ全体を先読みさせず、依頼ごとにレビュー・パケットを作る。
- パケットには目的、圧縮した前提、既知の主張、読む範囲、出力上限、停止条件を含める。
- 既知事項への同意を長く再掲させず、反証、重大度変更、新規Findingを優先させる。
- コードは対象行を指定し、疑義がある場合だけ周辺やデータを追加確認する。
- 初回Claudeレビューの正本は `reviews/CLAUDE_REVIEW_PACKET.md` とする。
