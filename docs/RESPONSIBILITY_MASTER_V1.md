Date: 2026-09-05
Status: Seed catalog / metadata pass pending

## 記号

- `M`: Household responsibility / management。気づく・判断・閉じる責任
- `R`: Routine execution。繰り返し実行
- `S`: 健康・安全。一次情報の根拠が必要
- `C`: 家庭・園・地域設定に依存

このファイルは「項目数を増やすためのリスト」ではなく、家庭運営を網羅するための初期マスターである。次工程で各項目に applicability / trigger / cadence / close condition / evidence / source を付与する。
