# v0.2 Slice 01 — 状態から今日の一手を選ぶ

Status: Ready for implementation
Date: 2026-08-30

## 1. 目的

v0.2の核 C-01〜C-05 を7〜14日の実生活で試せる最小実装を、既存の1ファイルHTMLへ入れる。

最初のSliceでは、旧来の「全タスクを並べ、件数・XP・達成率を進める」体験を今日画面から外し、次のループを成立させる。

`家の状態を確認する → 0〜3件から自分で一手を選ぶ → 完了/あとで/見送る → 記録に基づく事実を残す`

## 3. 実装するもの

### 今日

- 余力 `守る日 / 回す日 / 先回り日`
- アクティブカード 0〜3件
- カード最上位は状態事実
- `今やる`で利用者が「現在の一手」を選ぶ
- `完了 / あとで / 今日は見送る / もう済んでいた`
- 完了と先読み達成のUndo
- `今日のあとで`への退避と手動復帰
- 0件時の休息肯定表示
- `提案になかったことに気づいた`

### 状態

- `十分 / そろそろ / 切れた`の3段階
- 利用者入力状態は当日のみ現在事実
- 翌日は古い値を現在状態として見せず、最終確認日を表示
- `1日1問`の`分かる`は把握記録のみで状態鮮度を延長しない
- 同領域で`分かる`2回連続なら3日だけ質問を休止

### 先読み

- 設定・曜日・月齢から静的に最大3件
- 自動で今日へ入れない
- 満杯時は4件目を作らず、既存1件との入替か追加中止

### 担当

- 完結ループの閲覧のみ
- 担当選択、認定、工程別進捗は実装しない

### 成長

- 期間の`0回`集計を作らない
- 固定証拠ルールを満たす出来事だけ表示
- 最小ルール:
  - 当日の`そろそろ`確認 → 対応する補充完了
  - 保存済み期限 → 期限前の準備完了
- `自分で気づけた`のローカル記録
- 主語つきの手柄、空虚な称賛、XP、連続記録を出さない

## 4. 保存・移行

既存キー `kajitori_stable_mvp_v2` は変更しない。

既存オブジェクト内の `tasksByDate / missedLog / retryQueue` 等の旧データは削除・上書きせず、`v02` 名前空間を追加する。

```text
kajitori_stable_mvp_v2
├─ tasksByDate        # 旧データ・保持
├─ missedLog          # 旧データ・保持
├─ retryQueue         # 旧データ・保持
└─ v02                # 新規
   ├─ profile
   ├─ days
   ├─ stateFacts
   ├─ questionHistory
   ├─ evidenceEvents
   └─ spontaneous
```

`明日リトライ`用の旧`retryQueue`は削除しないが、v0.2の新規フローでは使用しない。

v0.2の初期化操作は`v02`だけを消し、旧データを消さない。

localStorage保存失敗は画面に通知する。

## 6. Slice 01受入条件

`docs/V0_2_UX_SPEC.md` のA-01〜A-22のうち、今回実装範囲に含まれるものを満たす。特に次をブロッカーとする。

| 条件 | 必須確認 |
|---|---|
| A-02 | 今日のアクティブカードが絶対に3件を超えない |
| A-10 | 今日画面から達成率・XP・数値ゲージ・取り逃がしを撤去 |
| A-11 | 前日の3段階状態を現在状態として表示しない |
| A-16 | 未選択候補を自動で開始しない |
| A-19 | 満杯時追加は入替または中止で、4件目を作らない |
| A-20 | 欠測から`0回`を生成しない |
| A-21 | `あとで`を同日自動再提示しない |
| A-22 | 保存失敗を成功扱いしない |

## 7. 検証

実装後に最低限次を確認する。

1. HTML/JavaScript構文チェック。
2. 新規状態で初回設定→今日画面まで到達。
3. 旧形式のlocalStorageオブジェクトへ`v02`を追加しても旧キーが残る。
4. 守る日/回す日/先回り日の上限が1/2/3を超えない。
5. 今日3件時の先読み追加で4件にならない。
6. `あとで`が同日自動復帰しない。
7. 日付が変わると前日の状態値を現在見出しに使わない。
8. `そろそろ`→補充完了だけが対象の証拠イベントを作り、`切れた`→補充や証拠欠けでは作らない。
9. Undoが直前操作を戻す。
10. 保存失敗時に利用者向けエラーを出す。
11. 主要ボタンが44px相当以上で、スワイプ必須操作がない。

P0/P1が残った場合はSlice完了にしない。
