# Claude UI concept packet: v0.2 first slice

Status: Active

## 役割

育児中の片手操作と、生活アプリの感情設計に強いシニアモバイルUIデザイナーとして、v0.2の実装前UIコンセプトを1案作る。今回は仕様レビューではなく、見て触って判断できるデザイン提案が成果物。

## 読む範囲

このパケットだけを読む。トークン消費を抑えるため、既存HTML、旧レビュー、他の文書、外部サイトは読まない。

## プロダクトの確定事項

| 項目 | 確定内容 |
|---|---|
| 一文 | 家庭の次の一手に自分で気づき、判断し、閉じる力を育てる先読みトレーナー |
| 最初の利用者 | 育休中に日中も家庭運営を担う父親。基本場面は新生児家庭 |
| 今日の核 | 余力に応じた0〜3件、理由カード、利用者が選ぶ現在の一手 |
| 成功 | アプリ利用時間や家事件数ではなく、先回りして自分で回せる領域が増えること |
| パートナー | インストール、入力、承認、採点を求めない。偶然画面を見ても監視に感じさせない |
| ゲーム感 | 家事件数のXP・達成率・連続記録ではなく、判断・先読み・完結が育つ感覚 |

## 現行モックの視覚的な出発点

- 390×844pxのスマートフォン枠。
- オフホワイト、セージ、テラコッタ、ゴールドの暖色寄りパレット。
- 18px前後の角丸カードと薄い影。
- 現状は達成率リング、XP、レベル、件数統計が上部を占め、本文9〜12pxと小さい。
- v0.2では暖かさを残してよいが、現在のレイアウトを踏襲する必要はない。

## 推奨する方向

一貫した1案だけを深く作る。方向名は仮に「静かな作戦室」とする。

- 大人向けで、落ち着いていて、少しゲームらしい。
- 育児記録アプリの甘さ、業務ToDoの冷たさ、男性向けを意識しすぎた無骨さを避ける。
- 一番強い視覚要素はスコアではなく「次の候補」または自分で選んだ「現在の一手」。
- 理由と終わりの条件を、説教や長文に見せず理解できる。
- 睡眠不足でも視線の順番に迷わず、抱っこ中に親指だけで操作できる。

## 作る画面状態

デスクトップではスマートフォンの外側に状態切替と短いデザインノートを置く。スマートフォン幅では本体だけを自然に表示する。

| 状態 | 必須内容 |
|---|---|
| 候補 | `回す日`、今日の候補2件、各カードの理由・終わりの条件、`今やる` |
| 実行中 | 利用者が選んだ現在の一手を大きく表示。`完了 / あとで / 今日は見送る` |
| 守る日0件 | `今日は増やさなくて大丈夫`、休息を肯定する本文、控えめな`先読みを見る` |
| 完了直後 | `今日できたこと`へ項目名を追加し、Undoできる。紙吹雪や大げさな称賛は不要 |
| 先読み | 明日・今週の芽。利用者が選ぶまで今日へ自動追加しない |

すべての今日画面状態に、44px以上の`提案になかったことに気づいた`入口を配置する。主要ナビゲーションは`今日 / 先読み / 担当 / 成長`の4つを示すが、今回詳細を作るのは今日と先読みだけでよい。

## 使用する具体例

| タスク | 今やる理由 | 終わりの条件 |
|---|---|---|
| 夜間セットを補充 | 寝る前にそろえておくと、夜中に探さずに済む | オムツ、ガーゼ、着替えが所定数そろった |
| オムツの次サイズを確認 | 生後3か月。サイズアップの兆候を確認する時期 | 体重・跡・漏れを確認し、買うか保留を決めた |

状態語は`今日やる / あとで / 今日は見送る / 完了 / もう済んでいた / 今は不要`。誰が対応したか、妻、取り逃がし、未回収という語は出さない。

## UI制約

- 本文14px以上、主要タップ領域44px以上。
- 色だけで状態を区別しない。
- 強い白背景を避け、夜間でも刺激が強すぎない。
- `prefers-reduced-motion`へ配慮する。
- 達成率、数値ゲージ、XP、レベル、ランキング、連続記録、夫婦比較を出さない。
- 1画面へ情報を詰め込みすぎず、重要でない説明は段階的に見せる。
- 外部画像、外部フォント、CDN、ライブラリを使用しない。アイコンが必要ならCSSまたはインラインSVGを使う。

## 出力契約

`prototypes/claude_v0_2_ui_concept.html`だけを新規作成する。

- 単体でブラウザ表示できるHTML/CSS/最小Vanilla JavaScript。
- 本番ロジック、localStorage、タスク生成、データ移行は実装しない。
- 画面状態を切り替えて、主要操作と視覚階層を確認できるようにする。
- デスクトップのスマートフォン外側に、方向名、意図3点、主要カラートークンを簡潔に表示する。
- コードは520行以内を目安とし、過剰なコメントや仕様の再掲をしない。
- 3案の薄いバリエーションではなく、推奨する1案を完成度高く提示する。

既存の`kajitori_minimal_pictogram_compact.html`、仕様、レビュー、`HANDOFF.md`は変更しない。別の説明Markdownも作らない。成果物を作成したら終了する。
