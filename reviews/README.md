# Reviews

ClaudeとCodexの相互レビュー記録を保存します。

## ファイル名

`YYYY-MM-DD-NNNN-agent-topic.md`

例: `2026-07-22-0001-claude-product-ux.md`

`0000-baseline-codex.md` は、相互レビューワークフロー導入前の初期ベースラインです。

ClaudeへレビューやUI案を依頼する場合は、依頼別のパケットを使い、必要な文書とコード範囲だけを指定します。現在の依頼は`CLAUDE_UI_CONCEPT_PACKET_V0_2.md`です。

## 運用ルール

- 1ファイルにつき、1つのレビュー範囲を扱う。
- レビュー対象のコミットまたはファイル状態を明記する。
- Reviewerはレビュー中にアプリ本体を変更しない。
- Implementerの回答を同じファイルの下部へ追記する。
- 解決後もファイルを削除せず、判断履歴として残す。
- 指摘形式は `docs/COLLABORATION_WORKFLOW.md` に従う。
- パケットごとに、実装監査、企画、UI/UXなどレビューの役割を1つに絞る。
- 既知事項の再要約を求めず、そのレビューで必要な新規提案・反証・MVP判断へ出力を限定する。

## テンプレート

`TEMPLATE.md` をコピーして使用してください。
